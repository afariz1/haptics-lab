# Haptics Lab

One-page demo for the TAMa essay *Multisensory Feedback (Haptics and Sounds)*, FIT VUT 2026/27.

Tap the button and feel how the delay between touch and feedback (0 / 50 / 100 / 200 ms, or blind random) changes the experience.

- Android + Chrome: vibration (Web Vibration API) + click sound + flash
- iPhone / Safari: click sound + flash only (no vibration API in Safari)

Live: https://afariz1.github.io/haptics-lab/
